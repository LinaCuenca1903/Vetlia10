Centro de soporte y manuales Vetlia 🐾

¿Cómo restablecer mi contraseña?
Ve al inicio de sesión, haz clic en "¿Olvidaste tu contraseña?" recibe tu correo y sigue los pasos.
¿Cómo registrar un nuevo usuario? Admin
Ve a usuarios en el dashboard y llena los datos.
🔐 ¿Cómo crear una contraseña segura? Admin
Tu contraseña debe: Tener mínimo 8 caracteres (recomendado 12 o más). Incluir al menos: 1 letra mayúscula (A–Z) 1 letra minúscula (a–z) 1 número (0–9) 1 carácter especial (! @ # $ % & * ?) No contener tu nombre, apellido o correo. No ser una contraseña común (ej: 123456, password, admin123).
¿Cómo obtengo soporte con mi inicio de sesion?
Puedes escribir a soporteclientmerge@gmail.com o llamar al numero 3013340793.
Solución a problemas comunes Vetlia.
🔐 No puedo iniciar sesión
  • Verifica que el correo y contraseña sean correctos.
  • Revisa si tienes activada la tecla Bloq Mayús.
  • Usa “¿Olvidaste tu contraseña?” si no recuerdas tu acceso.
📅 La cita no aparece registrada
  • Verifica que hayas seleccionado una mascota.
  • Confirma que la fecha y hora estén disponibles.
  • Actualiza la página e intenta nuevamente.
🐾 No aparecen pacientes o tutores
  • Revisa que el paciente haya sido guardado correctamente.
  • Comprueba conexión con la base de datos.
  • Actualiza la lista usando el botón “Ver”.
🧾 La cotización no se guarda
  • Debes seleccionar una mascota.
  • Debe existir al menos un producto o servicio agregado.
  • Verifica que el usuario tenga sesión iniciada.
📄 El PDF no descarga
  • Verifica que la carpeta fpdf exista dentro del proyecto.
  • Comprueba que el navegador no bloquee ventanas emergentes.
  • Revisa que la cotización exista en la base de datos.
💊 El catálogo no muestra imágenes
  • Verifica que las imágenes estén dentro de uploads.
  • Comprueba permisos de la carpeta.
  • Asegúrate de cargar imágenes válidas.
📧 El correo no se envía
  • Verifica configuración SMTP.
  • Revisa usuario y contraseña del correo.
  • Comprueba conexión a internet.
⚠ Error de conexión con la base de datos
  • Verifica que XAMPP esté encendido.
  • Comprueba que MySQL esté iniciado.
  • Revisa nombre de la base de datos y credenciales.
🖥 El sistema carga lento
  • Pueden existir demasiados registros cargados.
  • Verifica conexión de red.
  • Limpia caché del navegador.
🔄 Los cambios no se reflejan
  • Presiona Ctrl + F5.
  • Limpia caché del navegador.
  • Verifica que estés editando el archivo correcto.
👨‍⚕️ Problemas de permisos o roles
  • Algunos módulos son exclusivos del administrador.
  • Verifica el rol del usuario en la base de datos.
🐶 Error al crear historias clínicas
  • Debe existir una mascota registrada.
  • Completa los campos obligatorios.
  • Verifica conexión con el servidor.
